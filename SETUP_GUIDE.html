Network Alert

Step-by-step setup guide: ping your network on a schedule and get an email when a link goes down or comes back.

1. What this project does

Network Alert is one Python script. A scheduler runs it every 5 minutes. Each run pings a list of addresses you choose, such as your router, your ISP gateway, a server, or 8.8.8.8 for the internet.

  • When an address stops answering, you get one DOWN email.
  • When it answers again, you get one UP email with the time it went down.
  • While it stays down, no extra mail is sent.
  • If a mail cannot be sent, it is saved and retried on the next run.

Each check sends 3 pings and waits 2 seconds for each reply. One reply counts as up. Raise FAIL_THRESHOLD to ignore short blips: 3 means about 15 minutes of misses before a mail.

Finding your own IPs for TARGETS

WhatHow to find it
Your router (default gateway)Linux: ip route | grep default
macOS: netstat -nr | grep default
Windows: ipconfig, look for "Default Gateway"
ISP gatewayRun traceroute 8.8.8.8 (Windows: tracert 8.8.8.8). The first public address after your router is usually the ISP gateway.

Ping every address once before adding it, for example ping -c 3 192.168.1.1. If an address never answers ping, for example because a firewall blocks ping, it will send a DOWN mail on the first check.

5. Step-by-step setup on Linux or macOS

Step 1. Install the dependencies.

sudo apt update
sudo apt install python3 iputils-ping cron

Step 2. Copy the project folder to your home folder and go into it.

cp -r net-alert ~/net-alert
cd ~/net-alert

Step 3. Run the installer once. It creates config.env and stops.

./install.sh

Step 4. Edit config.env. Change every line marked CHANGE, especially MAIL_TO, SMTP_USER, SMTP_PASSWORD, and TARGETS.

nano config.env

Step 5. Ping each address in TARGETS.

ping -c 3 192.168.1.1

Step 6. Run the installer again. It sends a test mail, runs one check, and adds the cron job.

./install.sh        # every 5 minutes
./install.sh 10     # or every 10 minutes

A good run prints mail sent to you@example.com, then the current state, then the cron line:

*/5 * * * * /usr/bin/env python3 /home/you/net-alert/net_alert.py

Step 7. Check your inbox for the test mail, and watch the log.

tail -f ~/net-alert/state/alerts.log

Manual setup without install.sh

cp config.env.example config.env
chmod 600 config.env
nano config.env
python3 net_alert.py --mail-test
python3 net_alert.py
crontab -e
# add this line, with your own path:
*/5 * * * * /usr/bin/env python3 /home/you/net-alert/net_alert.py

6. Step-by-step setup on Windows

Step 1. Install Python from python.org and tick Add python.exe to PATH.

Step 2. Copy the net-alert folder to, for example, C:\net-alert.

Step 3. Copy config.env.example to config.env and edit it in Notepad.

cd C:\net-alert
copy config.env.example config.env
notepad config.env

Step 4. Test mail, then one check.

py net_alert.py --mail-test
py net_alert.py
py net_alert.py --status

Step 5. Find the full path of Python.

where pythonw

Step 6. Create a task that runs every 5 minutes. pythonw.exe runs without opening a window. Use the path from Step 5.

schtasks /Create /SC MINUTE /MO 5 /TN "NetAlert" ^
  /TR "\"C:\Users\you\AppData\Local\Programs\Python\Python312\pythonw.exe\" \"C:\net-alert\net_alert.py\""

To run it even when you are signed out, open Task Scheduler, find NetAlert, and choose Run whether user is logged on or not.

Remove it later with schtasks /Delete /TN "NetAlert" /F.

7. Mail account setup (app password)

Gmail

  1. Open myaccount.google.com and go to Security.
  2. Turn on 2-Step Verification.
  3. Search for App passwords and create one named "Network Alert".
  4. Put the 16-character password in SMTP_PASSWORD. Do not include spaces.
MAIL_METHOD=smtp
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_SECURITY=starttls
SMTP_USER=you@gmail.com
SMTP_PASSWORD=abcdefghijklmnop

Outlook / Microsoft 365

SMTP_HOST=smtp.office365.com
SMTP_PORT=587
SMTP_SECURITY=starttls

Work accounts often need an administrator to allow authenticated SMTP. If login is refused, use a personal Gmail account for the alert.

config.env contains this password. Keep it private, do not email it, and do not upload it. .gitignore already keeps it out of Git.

9. Troubleshooting

ProblemCause and fix
Missing config.envCopy config.env.example to config.env.
mail FAIL ... AuthenticationWrong SMTP_USER or password. Use an app password, not your normal one.
mail FAIL ... timed outPort 587 is blocked. Try SMTP_PORT=465 with SMTP_SECURITY=ssl.
DOWN mail on first run for a working deviceThe device blocks ping. Remove it from TARGETS, or allow ping on that device.
No mail when the internet is downExpected for smtp mode: mail cannot leave without internet. It is queued in state/pending.json and sent when the link returns.
Cron never runscrontab -l to confirm the line. Make sure the path is absolute and the cron service is running: systemctl status cron.
Laptop sleepsNo checks run while the laptop is asleep. Use a PC, Raspberry Pi, or server that stays on.

10. Limits

  • It only knows what ping can see. A device that blocks ping looks down.
  • If your gateway still answers ping while something behind it is broken, that line stays up. Add 8.8.8.8 as a second check.
  • In smtp mode, the DOWN mail for "internet is down" arrives after the internet returns, because it is queued until then.
